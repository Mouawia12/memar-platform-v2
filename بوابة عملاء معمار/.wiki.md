# Project Summary
تطبيق ERP للـ Client Portal بلوحة RTL Glassmorphism لإدارة وتتبع مشاريع العميل وما يرتبط بها من CRM وDMS وRequests/Approvals والمهام والاتصالات، مع توسيع مناطق العرض داخل صفحة البورتال لدعم أجزاء مشاريع جديدة (04-07)، وإضافة صفحة Employee Portal منفصلة تعرض وظائف الموظف اليومية (Dashboard والمهام والمشاريع والحضور والإجازات والراتب والتقارير والوثائق والدردشة والإشعارات والملف الشخصي وكود الإحالة) بأسلوب تصميم موحّد.

# Project Module Description
- توسعة مناطق Portal للأجزاء 04-07: تحديث هيكل الواجهة ومنطق فتح/إظهار أجزاء الواجهة وربطها بمكوّنات مثل Kanban والتقويم وDMS عبر سكربت الواجهة وأنماط RTL.
- إضافة Employee Portal (صفحة متعددة الصفحات عبر Vite):
  - توفير واجهة `employee-portal.html` بترتيب RTL (Sidebar/Topbar/Main pages) لصفحات الموظف المختلفة.
  - توفير تصميم `employee-portal.css` لمنظومة UI: أزرار وشارات وجداول وبطاقات وlayout للدردشة والإحالة والـ Toast.
  - توفير سلوك `employee-portal.js` للتنقل بين الصفحات وتفعيل التمييز في الـ Sidebar وتوليد الـ Toast وتحديث تاريخ التحية.

# Directory Tree
- app/frontend/
  - index.html: صفحة الـ Portal الحالية (RTL) وتوسعة مناطق Parts 04-07.
  - style.css: أنماط Glassmorphism وRTL لمناطق الأقسام.
  - script.js: منطق تفاعلي لربط مناطق الواجهة وتبديلها.
  - employee-portal.html: صفحة Employee Portal RTL (متعددة الأقسام داخل نفس الصفحة عبر صفحات منطقية).

  - employee-portal.js: JS لتنقل الصفحات والـ Toast وسلوك Sidebar وتحديث التحية.
  - vite.config.js: إعداد Vite multi-page تشمل `index.html` و `employee-portal.html`.
  - package.json: تبعيات وبنيات Frontend.
  - .mgx/config.yaml: إعدادات تشغيل بيئة MGX.

# File Description Inventory
- app/frontend/index.html: هيكل Dashboard وRTL للـ Client Portal مع توسعة مناطق Part 04-07.
- app/frontend/style.css: تنسيقات RTL وGlassmorphism لأقسام مثل المهام/المواعيد/زيارات الموقع/DMS.
- app/frontend/script.js: منطق التفاعل وتبديل عرض الأقسام وربط السلوك عند توفر البيانات.
- app/frontend/employee-portal.html: واجهة Employee Portal RTL مع أقسام: Dashboard، المهام، المشاريع، الحضور، الإجازات، الراتب، التقارير، الوثائق، الدردشة، الإشعارات، الملف الشخصي، الإحالة.
- app/frontend/employee-portal.css: تصميم Employee Portal (Layout + Cards + Tables + Chat + Referral + Toast + Responsive).
- app/frontend/employee-portal.js: تنقل بين الصفحات داخل employee-portal + Toast + toggleSidebar + تحديث تاريخ التحية.
- app/frontend/vite.config.js: يضبط إدخالات البناء لصفحتين: `index.html` و`employee-portal.html`.

# Technology Stack
- HTML (RTL)
- CSS (Glassmorphism + تصميم لوحات/مكونات + Responsive)
- Vanilla JavaScript (منطق التفاعل: تبديل صفحات/Toast/Sidebar)

# Usage
- انتقل إلى `app/frontend`
- ثبّت تبعيات الواجهة حسب `package.json`
- شغّل أو نفّذ مهام البناء/التشغيل المحددة ضمن `package.json` (مع دعم build لصفحة `employee-portal.html` عبر Vite multi-page)
