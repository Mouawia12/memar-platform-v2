# 1. Security Vision

يجب تصميم نظام الصلاحيات في **MEMAR ERP** كنظام مؤسسي متكامل، وليس مجرد إخفاء وإظهار صفحات.

الصلاحيات يجب أن تتحكم في:

* الصفحات.
* الأقسام.
* البيانات.
* الإجراءات.
* الملفات.
* التقارير.
* عمليات الموافقة.
* التصدير.
* الحذف.
* التعديل.
* الوصول حسب المشروع أو القسم أو الموظف.

الهدف:

> كل مستخدم يرى ويستخدم فقط ما يسمح له به حسب دوره ومسؤوليته.

---

# 2. Permission Architecture

اعتماد نظام:

## RBAC

(Role Based Access Control)

مع:

## ABAC

(Attribute Based Access Control)

للسيطرة على الوصول حسب خصائص إضافية.

مثال:

المهندس يمكنه رؤية:

* المشاريع المكلف بها فقط.

مدير القسم يمكنه رؤية:

* جميع مشاريع قسمه.

الإدارة العليا يمكنها رؤية:

* كل المشاريع.

# 7. Action Permission Matrix

كل زر في النظام مرتبط بصلاحية.

مثال:

زر:

"حذف"

لا يظهر إلا إذا:

```
permission.delete.project = true
```

زر:

"اعتماد"

يحتاج:

```
permission.approve.contract = true
```

# 8. Data Level Permission

ليس فقط صلاحية الصفحة.

مثال:

المهندس يرى صفحة المشاريع:

لكن:

يرى فقط:

```
Projects
WHERE assigned_engineer = current_user
```

---

مدير المشاريع:

```
Projects
WHERE department = current_department
```

---

الإدارة:

```
ALL PROJECTS
```
