# 1. Database Philosophy

يجب بناء قاعدة بيانات **Enterprise Grade** تعتمد على:

**PostgreSQL + Supabase**

وتكون قاعدة البيانات هي:

## Single Source of Truth

أي أن:

* كل البيانات الأساسية تحفظ في قاعدة البيانات المركزية.
* جميع الوحدات تعتمد على نفس البيانات.
* لا يتم تكرار بيانات العميل أو المشروع.
* جميع العلاقات تعتمد على UUID.
* جميع العمليات تسجل في Audit Trail.

---

# 2. Database Architecture Principles

## Primary Key

كل جدول يستخدم:

```
UUID
```

بدلاً من:

```
Integer ID
```

لأسباب:

* الأمان.
* التوسع.
* التكامل مع API.
* سهولة المزامنة.

---

# 3. Common Fields

كل جدول رئيسي يجب أن يحتوي على:

```sql
id UUID PRIMARY KEY

created_at TIMESTAMP

updated_at TIMESTAMP

created_by UUID

updated_by UUID

is_active BOOLEAN

deleted_at TIMESTAMP NULL
```

# 18. Database Security

تطبيق:

## Row Level Security (RLS)

مثال:

المهندس يرى:

* المشاريع المكلف بها فقط.

المحاسب يرى:

* الحسابات والفواتير فقط.

المدير يرى:

* كل البيانات.
