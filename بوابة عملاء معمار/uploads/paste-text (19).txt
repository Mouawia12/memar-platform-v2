# MEMAR ERP MASTER PROMPT

# PART 19

# AUTOMATION RULES & WORKFLOW ENGINE

# (Business Process Automation System)

---

# 1. Workflow Engine Vision

يجب أن يحتوي نظام **MEMAR ERP** على محرك Workflow مركزي مسؤول عن تشغيل جميع العمليات التلقائية داخل الشركة.

الهدف:

تحويل النظام من مجرد صفحات إدخال بيانات إلى نظام ذكي يدير دورة العمل بالكامل.

أي حدث داخل النظام يمكن أن يؤدي إلى:

* إنشاء مهمة.
* إرسال إشعار.
* تغيير حالة.
* إنشاء مستند.
* طلب موافقة.
* تحديث تقرير.
* تشغيل Automation أخرى.

---

# 2. Workflow Architecture

هيكل العمل:

```
Trigger
   |
   |
Workflow Engine
   |
--------------------------
|          |             |
Action   Condition    Approval
|
|
Update Database
Send Notification
Create Task
Generate Document
```

---

# 3. Workflow Components

كل Workflow يتكون من:

## Trigger

الحدث الذي يبدأ العملية.

أمثلة:

* إنشاء عميل جديد.
* تحويل Lead.
* توقيع عقد.
* إصدار فاتورة.
* انتهاء موعد.
* رفع مستند.
* تغيير حالة مشروع.
* تسجيل حضور.
* اعتماد طلب.

---

## Conditions

شروط تنفيذ العملية.

مثال:

إذا:

```
Project Status = Contract Signed
```

و

```
Payment Received > 40%
```

إذن:

إنشاء مشروع تنفيذي.

---

## Actions

الإجراءات الناتجة.

مثل:

* إنشاء Task.
* إرسال Email.
* إرسال WhatsApp.
* إنشاء Folder.
* تعديل Status.
* إنشاء Invoice.
* إرسال Approval Request.

---

# 4. CRM Automation

## Lead Creation

عند إنشاء Lead جديد:

النظام يقوم تلقائياً بـ:

1. إنشاء رقم Lead.
2. تحديد مصدر العميل.
3. تعيين مسؤول المبيعات.
4. إرسال Notification.
5. إنشاء أول Task للمتابعة.
6. إضافة Timeline Event.

---

# 5. Lead Follow-up Automation

إذا لم يتم التواصل مع العميل خلال:

24 ساعة

النظام:

* يرسل Reminder لمسؤول المبيعات.
* يظهر العميل في قائمة "متابعة عاجلة".

---

إذا مر:

3 أيام بدون تحديث:

* تصعيد للمدير.
* تغيير درجة الأولوية إلى High.

# 21. Workflow Builder

الإدارة تستطيع إنشاء Workflow بدون برمجة.

واجهة Drag & Drop:

```
WHEN
[Event]

IF
[Condition]

THEN
[Action]
```

مثال:

```
WHEN
New Contract

IF
Payment Received

THEN
Create Project
Assign Engineer
Send Notification
```
