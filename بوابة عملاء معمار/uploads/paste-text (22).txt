# 1. User Profile Card (Sidebar Header)

## الهدف

إضافة بطاقة بيانات المستخدم في أعلى الـ Sidebar قبل عناصر القائمة الرئيسية.

يجب أن تكون ثابتة في جميع صفحات النظام.

---

## User Profile Card Design

الموقع:

```
Sidebar Top Area
↓
User Profile Card
↓
Navigation Menu
```

---

## محتويات البطاقة:

### صورة المستخدم

* Profile Image
* Avatar
* إمكانية رفع صورة جديدة
* تغيير الصورة من الإعدادات

---

### بيانات المستخدم:

* الاسم الكامل
* الوظيفة / المسمى الوظيفي
* القسم
* رقم الموظف
* رقم الحساب الداخلي
* البريد الإلكتروني
* رقم الهاتف

مثال:

```
----------------------
[ صورة الموظف ]

أحمد محمد علي

Project Manager

Engineering Department

Employee ID:
EMP-00025

Account No:
MEM-10254

----------------------
```

---

## Actions

عند الضغط على البطاقة:

يفتح:

* الملف الشخصي
* تعديل البيانات
* تغيير كلمة المرور
* إعدادات الحساب
* تسجيل الخروج

# 2. Home Dashboard Hero Section

## Hero News & Internal Ads System

إضافة مساحة Hero في الصفحة الرئيسية للإدارة والموظفين.

الغرض:

عرض الأخبار الداخلية والإعلانات والتنبيهات المهمة.

---

## Hero Location

المكان:

```
Dashboard Top Area

بعد Welcome Header مباشرة

وقبل KPI Cards
```

---

## Hero Content Types

يدعم:

### 1- أخبار الشركة

مثال:

* تحديث نظام جديد
* تعليمات إدارية
* أخبار المشاريع
* تعاميم داخلية

---

### 2- إعلانات داخلية

مثل:

* موعد اجتماع عام
* تدريب الموظفين
* تحديث سياسة العمل
* إجازات رسمية

---

### 3- تنبيهات تشغيلية

مثل:

* انتهاء موعد مشروع
* تأخر مهمة
* مستند ناقص
* اعتماد مطلوب

بهذا التعديل يصبح النظام أقرب لبيئة تشغيل يومية لمكتب **مجموعة معمار للاستشارات الهندسية**، وليس مجرد CRM، بحيث يبدأ الموظف يومه من الصفحة الرئيسية ويرى:

* ماذا لديه من مهام.
* من يحتاج متابعة.
* مواعيده.
* أخبار الإدارة.
* بياناته الشخصية.
* العملاء والشركات المرتبطة به.

سأكمل بعد ذلك بالجزء التالي:
**Projects Management + Engineering Workflow + متابعة المشاريع الهندسية والتراخيص والإشراف**.
