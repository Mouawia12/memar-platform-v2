MEMAR ERP MASTER PROMPT
PART 06
DOCUMENT MANAGEMENT SYSTEM (DMS)
Enterprise Engineering Document Center

هذه الوحدة هي العمود الفقري للنظام بالكامل. ليست مجرد مدير ملفات، بل نظام إدارة وثائق هندسية متكامل (EDMS) يربط كل مستند بالمشروع، العميل، العقد، المهمة، والاعتماد الحكومي، مع تطوير الوحدات الموجودة في الملف مثل Document Editor وFile Manager وArchive.

1. Document Philosophy

يجب أن يعمل النظام وفق مبدأ:

Document-Centric ERP

أي أن جميع العمليات داخل النظام تدور حول المستندات.

كل مشروع.

كل عقد.

كل رسم.

كل تقرير.

كل خطاب.

كل بريد إلكتروني.

كل ملف.

يجب أن يكون له سجل كامل.

ولا يسمح بوجود ملفات خارج النظام.

CRM ← العقود والعروض والمراسلات.
Finance ← الفواتير والإيصالات.
Government Workflow ← الاعتمادات والكتب الرسمية.
HR ← ملفات الموظفين.
Meetings ← محاضر الاجتماعات.
Reports ← التقارير الدورية.
Document Editor ← إنشاء وتحرير المستندات.
File Manager ← إدارة التخزين.
Archive ← الأرشفة النهائية.
23. AI Quality Rules

قبل اعتماد أي مستند، يقوم النظام تلقائياً بالتحقق من:

وجود رقم المشروع.
وجود رقم المستند.
توافق اسم الملف مع سياسة التسمية.
اكتمال البيانات الوصفية (Metadata).
عدم وجود نسخة أحدث.
اكتمال دورة المراجعة.
وجود التوقيعات المطلوبة.
عدم وجود ملف مكرر.
نتيجة هذا الجزء

بعد تنفيذ هذه الوحدة، يصبح Memar ERP مزودًا بنظام Enterprise Document Management System (EDMS) متكامل، يتجاوز فكرة "مدير ملفات" إلى منصة مركزية لإدارة جميع الوثائق الهندسية والإدارية، مع تكامل كامل مع المشاريع، العملاء، الحسابات، والاعتمادات الحكومية، وبالاستفادة من الوحدات الموجودة في الملف الأصلي مثل Document Editor وFile Manager وArchive.
